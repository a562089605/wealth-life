## 政府债券

- 报价期限为 6、12、36、60 个月。每份面值 $1,000，买入价随游戏市场利率和通胀变化。买入时记录实际成交金额和固定年票息。持仓在月结时也按当期通胀估值。
- 买入成功打开刚成交的持仓。「我的债券」逐笔列示，按到期时间排序，并汇总本金和预计月票息。同一档的重复买入分别记录。
- 每月末按锁定票息支付，最后一个月末返还本金。详情分开显示「到期当月到账」与「持有到期合计」，金额按每期票息四舍五入到分计算。例如 6 个月、年票息 5.50% 的债券，每期 $4.58，到期当月 $1,004.58，从买入持有到期合计 $1,027.48。
- 债券市场采用确认的整页插画，屏幕实时绘制四档报价与按钮。页脚包含「我的债券」和「返回储蓄与投资」。购买预览和持仓详情用同套插画及动态字段排版。
