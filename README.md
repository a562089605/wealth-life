年度模式集中安排住房、工作、学习和生活重点。已经确定的合同延续，后台逐月结算；关键事件或资金不足时暂停。年末汇总由实际月账本生成。可以切回按月操作，保留原存档与已经发生的交易。

低生活状态进入三个月补救期，可以休息、联系朋友、治疗。现金缺口可用应急金、出售流动资产、减少预算或查看贷款；可预览延长期限的贷款重组合同。没有自动免债或凭空加现金。
