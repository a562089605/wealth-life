# 排班失败欠时：首次联动

2026-10-24：index及SW载入时间账本与time-flow包装；主管B协调不再预留最坏8h，选前明确提示失败8h、当前余额、可能欠时与返回月结后果；主动8h补班仍需时间足够。

失败后续确认前按实际可用时间记一次来源事件差额，后续工资/小费/经验仍在原记录中；确认结果后停止掷骰，继续按钮进入返回房屋月结卡。使用原月结入口及当月工资，不另发工资；旧月返回标记在次月自然失效，重复确认不推进两个月。刷新入口恢复待处理结果或返回卡。

时间预算扣除已登记的本月旧欠时；不重复扣事件全部8h和跨月差额。去除尚未实际执行的失败后续8h预留。超整月欠时仍阻塞并待规则处理。

7个局部测试脚本通过：开局、144地图组合、月结守卫、咖啡师卡、主管效果、时间账本、时间联动。时间联动测试月结为桩；不等于真实完整账务、手机或离线验收。
