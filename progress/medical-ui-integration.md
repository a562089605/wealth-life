# 医疗险及治疗入口首次接入

2026-10-24：medical-insurance.js提供基础200/80%、全额400/100%的互斥单保单选择。无险首次支付当月未付保费后生效，共用premiums凭证避免其他保费重复收；已有险改档或取消次月生效。旧health220且无coverage字段按旧全赔合同保留到玩家主动改；不静默改保费或降保障。原保险总览移除医疗复选框、改为独立入口，其他险原逻辑保留。普通旧随机医疗事件自付按有效赔付率计算。

recovery-ui.js接入低健康预览、锁定报价、付款/筹款、完整康复月份。房屋低健康安排本月，已探索月份安排次月完整康复，并复用当前月返回结算。<=15在后续事件展示前优先弹治疗；已执行事件记录保留、不重抽。康复阻止出门、工作调整及学历学习入口，工资等暂停由核心月结处理，最后恢复30/至少60/最多40/幸福保留。未付治疗时正常时间预算为0且不提前消费旧欠时。

12个当前工作树局部测试脚本通过，所有根JS语法通过。新增医疗险测试核对首次保费、重复确认、次月切换取消、序列化挂起合同、旧合同保留和合并收据；治疗UI测试核对预览不扣款、付款/执行幂等、地图次月康复及投保不追溯；核心月结使用实际函数另有测试。各测试的外部服务与DOM有替身，不是完整浏览器/手机或真实贷款全链路。

尚待：医疗中断的全部旧事件类型恢复、宠物康复委托、保险年度报价与出门后重购细节、必要账单付款门槛、全部旧学习/生活按钮防绕过、旧存档升级回归。首次接入不得标记完整医疗与保险系统验收。尚未部署；第2/4/5项仍未全部完成。
